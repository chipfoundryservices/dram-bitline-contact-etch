# dram-bitline-contact-etch

A series of technical e-books on plasma etch for semiconductor processing.

| # | Title | Folder |
|---|---|---|
| 30 | DRAM Bit-Line Contact Etch | [`books/30-dram-bitline-contact-etch`](books/30-dram-bitline-contact-etch) |

## Book layout (the pattern)

```
books/<NN>-<slug>/
  frontmatter.md      title page and preface
  chapters/NN-*.md    one Markdown file per chapter
  appendices/A-*.md   appendices
  backmatter/         glossary.md, index_terms.txt (index is generated)
  sim/                simulation code and its results (CSV)
  build/build.py      assembles HTML + EPUB into build/out/
  figures/            SVG figures generated by the build
```

Build: `pip install markdown numpy && python3 books/30-dram-bitline-contact-etch/build/build.py`
