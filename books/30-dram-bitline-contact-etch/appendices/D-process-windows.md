# Appendix D — Process Windows

Illustrative windows for the reference DC at F = 17 nm:

| Parameter | Window | Limit below | Limit above |
|---|---|---|---|
| top CD (buffer top) | 30.5–33.5 nm | area, BL-etch gap | neighbour clearance |
| buffer angle | 80.5–82.5° | contact area (bottom CD small) | BL-etch gap at depth |
| bottom CD (Si surface) | 24–28 nm | area becomes hole-limited | clearance < 9 nm |
| DC overlay, each axis (3σ) | ≤ 6 nm | — | R tail, neighbour touch |
| Si recess | 22–28 nm | damage left, poor plug anchoring | doping at interface, pit fill |
| STI / cap recess beside node | ≤ 5 nm (A); ≤ 28 nm (B) | — | cap margin, SNC pocket |
| liner pit beyond cap | ≤ 3 nm | — | BL–WL leakage, GIDL |
| cap left over WL metal | ≥ 30 nm | BL–WL breakdown | — |
| queue time, clean to fill | ≤ 4 h (wet clean) | — | interfacial oxide, R_DC |
| R_DC | ≤ 10 kΩ | — | write, sense margin |

The windows interact. A larger bottom CD widens the overlay window for resistance but narrows it for the neighbour. A silicon-selective recess widens the cap window and narrows the pit-fill window.
